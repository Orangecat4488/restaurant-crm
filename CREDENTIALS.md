# 🔐 Учётные данные и доступ к системе (Restaurant CRM)

В этом файле сохранены все стандартные учётные записи для входа в систему, их роли, пароли и уровни доступа.

> **Два отдельных приложения в этом репозитории.** Демо-аккаунты для каждого из них — разные, потому что они используют разные базы данных и бэкенды. Убедитесь, что вы входите в нужное приложение, и запускайте соответствующий бэкенд.

---

## 🅰️ Коммерческий портал (Commercial Portal)

**URL:** http://localhost:5173 (это папка `frontend/`)
**Бэкенд:** `backend/` (порт 5000) — Node.js + PostgreSQL или In-Memory fallback

| Роль | Email (Логин) | Пароль | Уровень доступа |
| :--- | :--- | :--- | :--- |
| **Администратор** | `admin@crm-restaurant.com` | `Admin@123456` | Полный доступ ко всем функциям |
| **Клиент ресторана** | `client@bistro.com` | `Client@123456` | Доступ к CRM ресторана |

Запуск:

```bash
cd backend
npm install
npm run seed            # ОДИН РАЗ — создаёт демо-аккаунты
npm run dev:admin       # запускает admin-api на :5000
```

В **другом** терминале:

```bash
cd frontend
npm install
npm run dev             # запускает фронтенд на :5173
```

> **Если вход не работает** ("Invalid email or password" или "Invalid credentials"), остановите backend и выполните:
> ```bash
> cd backend && npm run seed
> ```
> Это пересоздаст демо-пользователей с правильным хэшем пароля. В коде seed также есть автоматическая проверка: если пользователь уже существует, но его хэш пароля не совпадает с документированным демо-паролем, хэш будет перезаписан.

## 🅱️ Классическая CRM (Server)

**URL:** http://localhost:5173 (это папка `src/` в корне)
**Бэкенд:** `server/` (порт 3001) — Node.js + SQLite

| Роль | Email (Логин) | Пароль | Уровень доступа |
| :--- | :--- | :--- | :--- |
| **Администратор** | `admin@restaurant.com` | `admin123` | **Полный доступ (Superadmin)**:<br>• Управление персоналом (`/users`)<br>• Добавление, редактирование и удаление пользователей<br>• Управление меню, категориями и заказами<br>• Финансы, кассовая книга, закрытие смен, X/Z-отчёты<br>• Полная финансовая аналитика и отчёты |
| **Менеджер зала** | `manager@restaurant.com` | `manager123` | **Управление залом и сменой**:<br>• Управление блюдами и категориями меню<br>• Управление заказами и их статусами<br>• Кассовые смены (открытие, Z-отчёт, X-отчёт, инкассация, внесения)<br>• Просмотр отчётов и аналитики<br>• Просмотр списка сотрудников |
| **Сотрудник / Кассир** | `employee@restaurant.com` | `employee123` | **POS-Терминал кассира / официанта**:<br>• Оформление заказов через POS-терминал (`/cashier`)<br>• Добавление блюд, скидок, заметок к блюдам<br>• Приём оплаты (наличные, банковские карты, онлайн)<br>• Печать чеков и просмотр меню<br>*(Доступ к разделу «Пользователи» и удалению данных заблокирован)* |

## 🔑 Системные ключи и конфигурация (`.env`)

Ключи шифрования JWT хранятся в файле `server/.env`:
- `JWT_ACCESS_SECRET`: `crm-super-secret-access-token-key-2026-min-32-chars-long` (срок жизни access токена: 15 минут)
- `JWT_REFRESH_SECRET`: `crm-super-secret-refresh-token-key-2026-min-32-chars-long` (срок жизни refresh токена: 7 дней)
- `DB_PATH`: `./data/restaurant.db` (база данных SQLite)

## 🛠️ Как добавить нового пользователя или сменить пароль

### 1. Через веб-интерфейс (Рекомендуется):
1. Войдите под учетной записью **Администратора** (`admin@restaurant.com` / `admin123`) — для классической CRM, или `admin@crm-restaurant.com` / `Admin@123456` для коммерческого портала.
2. В боковом меню перейдите в раздел **«Пользователи»** (`/users`).
3. Нажмите кнопку **«+ Добавить сотрудника»**.
4. Введите имя, email, пароль и выберите роль (`admin`, `manager`, `employee`).
5. Нажмите **«Добавить»**.

### 2. Сброс базы данных к начальным данным:
Если потребуется сбросить базу данных и восстановить дефолтных пользователей:

```bash
# Классическая CRM (server/)
cd server
npm run db:init

# Коммерческий портал (backend/)
cd backend
npm run seed
```

## ❓ Если вход в коммерческий портал не работает

Самая частая причина — **демо-аккаунты не были созданы в `backend/`**. Решение:

```bash
cd backend
npm run seed
```

Эта команда создаст пользователей:
- `admin@crm-restaurant.com` / `Admin@123456`
- `client@bistro.com` / `Client@123456`

Если вы уже входили раньше, но теперь пароль не подходит, выполните ту же команду `npm run seed` — она автоматически перезапишет хэш пароля, чтобы он соответствовал документированным демо-учётным данным.

Затем перезапустите backend (`Ctrl+C` в его терминале и `npm run dev:admin` снова).
